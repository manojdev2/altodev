Introduction

Thank you for purchasing the EV ChargeFinder solution. This platform focuses on the full EV charging and fuel distribution journey: drivers discover nearby charging hubs or petrol/octane/diesel stations, reserve a slot before leaving home, and pay according to the reserved duration once they plug in or refuel. The experience is intentionally simple—pick a station, lock a slot, arrive on time, and the charger or pump is ready with the correct tariff applied.

The same workflow works for mixed fleets too. A rider booking octane for a bike or a logistics company lining up multiple diesel trucks can build an online serial queue, receive real-time reminders, and adjust the booking window if their schedule changes. The admin panel manages inventory, pricing slabs, wallets, loyalty rewards, push alerts, and reporting so you can operate EV charging and traditional fuels from a single console.

Google Maps API Key Setup

Create a Google Cloud project & enable billing

  1. Visit cloud.google.com/maps-platform and sign in with your Google account.
  2. Click Get Started, choose the Maps/Routes/Places products you need, and create a new project.
  3. Attach a billing profile when prompted (Maps Platform requires billing even for the free credit tier).

Generate & secure the API key

  1. Open APIs & Services → Credentials inside your project.
  2. Click Create credentials → API key. Google will show the key instantly in a modal.
  3. Choose Restrict key to limit HTTP referrers (web) or package name + SHA-1 (Android) and allow only required APIs (Maps SDK for Android, Places API, etc.).
  4. Copy the key and place it inside your app (e.g., android/app/src/main/AndroidManifest.xml under the meta-data tag or your env file).
  5. If the key leaks, regenerate it here and redeploy.

Backend Setup

1. How to run the backend

  1. Download & install Node.js – Visit nodejs.org, grab the LTS installer (e.g., Node.js 20), run the MSI, accept the license, and finish. npm is included automatically.
  2. Verify tools – In Command Prompt run node -v (expect something like v20.11.0) and npm -v (e.g., 10.2.4).
  3. Install helpful global packages – Example: npm install -g nodemon then check with nodemon -v.
  4. Initialize a project – If you’re starting fresh: mkdir my-node-project, cd my-node-project, npm init -y, then npm install express.
  5. Create a simple Express server – Build server.js: 
    const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Node.js server running 🚀");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
    Run it with node server.js and open http://localhost:3000.
  6. Useful commands – node file.js (run a script), npm install package (add dependency), npm install -g package (global install), npm run dev (custom dev script).

2. Node.js + MongoDB (Atlas + Mongoose)

  1. Install required packages – From your backend folder run: 
    npm init -y
npm install express mongoose dotenv
  2. Project structure example – 
    node-mongo-app/
├── server.js
├── .env
└── package.json
  3. Create MongoDB Atlas cluster – Go to mongodb.com/atlas, create an account, provision a cluster, click Connect → Connect your application, and copy the URI (e.g., mongodb+srv://username:password@cluster0.mongodb.net/myDatabase).
  4. Add credentials – In .env place: 
    MONGO_URI=mongodb+srv://username:password@cluster0.mongodb.net/myDatabase
PORT=5000
  5. Wire up server.js – 
    const express = require("express");
const mongoose = require("mongoose");
require("dotenv").config();

const app = express();
app.use(express.json());

mongoose.connect(process.env.MONGO_URI)
  .then(() => console.log("MongoDB Connected Successfully 🚀"))
  .catch((error) => console.log("MongoDB Connection Error:", error));

app.get("/", (req, res) => {
  res.send("Node.js + MongoDB API running");
});

const PORT = process.env.PORT || 5000;
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
  6. Create a model & insert data – 
    const mongoose = require("mongoose");

const userSchema = new mongoose.Schema({
  name: String,
  email: String,
  age: Number
});

const User = mongoose.model("User", userSchema);

app.post("/user", async (req, res) => {
  const user = new User(req.body);
  await user.save();
  res.json(user);
});
  7. Run the API – Execute node server.js. You should see “MongoDB Connected Successfully 🚀” and “Server running on port 5000”, then visit http://localhost:5000.

Payment Gateway Install

1. SSLCommerz

  • Create a merchant account at sslcommerz.com (choose Sandbox first).
  • After approval, collect your Store ID and Store Password from the dashboard.
  • In the admin panel → Payment Settings, paste those values, add the API domain, and select Sandbox or Live.
  • Trigger a test checkout; confirm the callback hits your backend endpoint before switching to production.

2. Stripe

  • Sign up or log in at dashboard.stripe.com/register and complete the verification steps.
  • Copy the Publishable key, Secret key, and create a webhook signing secret.
  • Update the admin panel Payment Settings with those keys and drop the webhook secret into your backend .env.
  • Use Stripe’s test cards to run payments and ensure the Node.js server receives and verifies webhook events.

Admin App Settings Reference

Where to enter SSLCommerz & Stripe keys

From the Next.js dashboard go to Settings ➜ App Settings. Use the Payment Gateways toggle to enable either Stripe or SSLCommerz, then paste the live/sandbox keys directly into the Stripe Credentials and SSLCommerz Credentials inputs as shown below. Don’t forget to set the minimum amount and choose Live/Test mode before saving.

How to change currency

In the same Settings ➜ App Settings page, scroll to Currency Settings. Pick a currency from the dropdown or manually override the Currency Code, Currency Symbol, and icon name. Click Save Settings to apply it to the entire platform.
